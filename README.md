# t-pose

**T-Pose** is a Letterboxd-inspired social platform for video games. Track what you’ve played, rate and review games, build curated lists, follow friends, and discover where to play games across platforms. All in a modern, performance-focused full-stack app.

Built with Next.js, TypeScript, PostgreSQL, and Prisma. Designed with a Y2K aesthetic and a strong focus on data modeling, accessibility, and test-driven development.
